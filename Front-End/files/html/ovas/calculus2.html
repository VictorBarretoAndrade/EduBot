Integrais Indefinidas, Funções Trigonométricas e Limites Fundamentais

Uma função F(x) é chamada de primitiva (ou antiderivada) de f(x) quando F′(x) = f(x). A família de todas as primitivas é representada pela integral indefinida ∫ f(x) dx = F(x) + C, onde C é a constante de integração. Essa dualidade entre derivar e integrar fica muito clara nas funções trigonométricas: como a derivada de f(x) = sin(x) é f′(x) = cos(x), segue imediatamente que a integral indefinida de f(x) = cos(x) é ∫ cos(x) dx = sin(x) + C.

A própria origem das derivadas trigonométricas e exponenciais repousa sobre três limites clássicos com indeterminação do tipo 0/0, que podem ser resolvidos por fatoração algébrica, geometria ou pela Regra de L'Hôpital (derivando numerador e denominador):

Exemplo resolvido passo a passo 1 (Derivada e Integral Trigonométrica):
Passo 1: Para encontrar a derivada de f(x) = sin(x), usamos a taxa de variação no ciclo trigonométrico: f′(x) = cos(x).
Passo 2: Para calcular a integral indefinida de f(x) = cos(x), buscamos a função cuja derivada é cos(x). Como (sin(x))′ = cos(x), concluímos que ∫ cos(x) dx = sin(x) + C.

Exemplo resolvido passo a passo 2 (Três Limites Clássicos 0/0):
• lim(x→0) sin(x)/x: É o limite trigonométrico fundamental. Quando x (em radianos) se aproxima de 0, sin(x) e x têm o mesmo comportamento linear (ou, por L'Hôpital, lim(x→0) cos(x)/1 = cos(0) = 1). Logo, lim(x→0) sin(x)/x = 1.
• lim(x→0) (e^x − 1)/x: É o limite exponencial fundamental (que define a derivada de e^x em x = 0). Aplicando L'Hôpital, derivamos numerador e denominador: lim(x→0) e^x / 1 = e⁰ = 1.
• lim(x→1) (x² − 1)/(x − 1): Fatorando a diferença de quadrados x² − 1 = (x − 1)(x + 1) e cancelando (x − 1) para x ≠ 1, temos lim(x→1) (x + 1) = 1 + 1 = 2.

Derivada de sin(x) e Integral de cos(x)

Derivar e integrar são operações inversas: a derivada de f(x) = sin(x) é cos(x), e portanto a integral indefinida de f(x) = cos(x) é sin(x) + C. Nunca se esqueça de somar a constante C nas integrais indefinidas!

Limites Fundamentais em x → 0

Dois limites notáveis aparecem em toda a engenharia: lim(x→0) sin(x)/x = 1 e lim(x→0) (e^x − 1)/x = 1. Ambos significam que, muito perto de x = 0, sin(x) ≈ x e e^x − 1 ≈ x.

Diferença de Quadrados em x → 1

Para calcular lim(x→1) (x² − 1)/(x − 1), fatoramos o numerador como (x − 1)(x + 1). Simplificando (x − 1), basta avaliar x + 1 em x = 1, obtendo 1 + 1 = 2.

Integral Definida, Teorema Fundamental do Cálculo e Substituição

Enquanto a integral indefinida retorna uma família de funções, a integral definida entre os limites a e b calcula o acúmulo total de uma grandeza — geometricamente, a área líquida sob a curva de f(x) no intervalo [a, b]. O Teorema Fundamental do Cálculo (TFC) conecta os dois conceitos: se F(x) é uma primitiva de f(x), então ∫ de a até b de f(x) dx = F(b) − F(a).

Quando o integrando é uma função composta do tipo f(g(x))·g′(x), aplicamos a técnica da substituição simples (a regra da cadeia ao contrário): definimos a nova variável u = g(x), calculamos o diferencial du = g′(x) dx e resolvemos ∫ f(u) du.

Exemplo resolvido passo a passo 1 (Área sob a curva pelo TFC): Calcule a área sob a curva de f(x) = 3x² no intervalo de x = 0 a x = 2.
Passo 1: Encontramos uma primitiva de f(x) = 3x²: F(x) = 3·(x³/3) = x³.
Passo 2: Aplicamos o Teorema Fundamental do Cálculo: Área = F(2) − F(0) = 2³ − 0³ = 8 − 0 = 8 unidades de área.

Exemplo resolvido passo a passo 2 (Integração por Substituição): Calcule ∫ 2x·cos(x²) dx.
Passo 1: Escolhemos u = x². Derivando, temos du = 2x dx.
Passo 2: Substituímos na integral: ∫ cos(x²) · (2x dx) = ∫ cos(u) du.
Passo 3: Sabemos que ∫ cos(u) du = sin(u) + C. Voltando para a variável x, obtemos sin(x²) + C.

O TFC transforma o cálculo de uma soma infinita de retângulos (Soma de Riemann) na simples diferença F(b) − F(a) entre os valores da primitiva nos extremos do intervalo.

Sempre que enxergar uma função interna u = g(x) multiplicada pela sua derivada g′(x) dx dentro da integral, troque por u e du. Ao final, retorne à variável original x.

Se f(x) ≥ 0 em todo o intervalo [a, b], a integral definida fornece exatamente a área entre o gráfico de f(x) e o eixo x. Na física, a área sob o gráfico da velocidade v(t) fornece o deslocamento total.

Pontos Críticos, Máximos, Mínimos e Testes da 1ª e 2ª Derivada

Para analisar o comportamento de curvas polinomiais de 2º e 3º graus, primeiro encontramos os pontos críticos resolvendo f′(x) = 0. Em seguida, classificamos cada ponto crítico usando o Teste da 1ª Derivada (se f′ muda de negativa para positiva, temos um mínimo; se muda de positiva para negativa, temos um máximo) ou o Teste da 2ª Derivada: avaliamos f″(x) no ponto crítico — se f″(x) > 0, a curva tem concavidade para cima e o ponto é um ponto de mínimo; se f″(x) < 0, a concavidade é para baixo e o ponto é um ponto de máximo.

Exemplo resolvido passo a passo 1 (Mínimo em f(x) = x² − 4x + 3):
Passo 1: Derivamos a função: f′(x) = 2x − 4.
Passo 2: Igualamos a zero: 2x − 4 = 0 ⇒ 2x = 4 ⇒ x = 2.
Passo 3: Como f″(x) = 2 > 0, o ponto de mínimo ocorre em x = 2.

Exemplo resolvido passo a passo 2 (Máximo em f(x) = −x² + 6x − 9):
Passo 1: Calculamos a primeira derivada: f′(x) = −2x + 6.
Passo 2: Igualamos a zero: −2x + 6 = 0 ⇒ 2x = 6 ⇒ x = 3.
Passo 3: Como f″(x) = −2 < 0, a função possui um ponto de máximo em x = 3.

Exemplo resolvido passo a passo 3 (Polinômio cúbico f(x) = x³ − 3x² + 2 em x = 2):
Passo 1: Calculamos a primeira derivada: f′(x) = 3x² − 6x = 3x(x − 2). Igualando a zero, os pontos críticos são x = 0 e x = 2.
Passo 2: Calculamos a segunda derivada: f″(x) = 6x − 6.
Passo 3: Avaliamos em x = 2: f″(2) = 6(2) − 6 = 12 − 6 = 6 > 0. Como f″(2) > 0, concluímos que x = 2 é um ponto de mínimo (já em x = 0, f″(0) = −6 < 0, que é ponto de máximo).

Mínimo em f(x) = x² − 4x + 3

Derivando f(x) = x² − 4x + 3, obtemos f′(x) = 2x − 4. Fazendo 2x − 4 = 0, encontramos x = 2. Como f″(2) = 2 > 0, o ponto de mínimo ocorre em x = 2 (onde f(2) = −1).

Máximo em f(x) = −x² + 6x − 9

Derivando f(x) = −x² + 6x − 9, obtemos f′(x) = −2x + 6. Resolvendo −2x + 6 = 0, chegamos a x = 3. Como f″(3) = −2 < 0, x = 3 é o ponto de máximo da função.

Curva Cúbica f(x) = x³ − 3x² + 2

Em f(x) = x³ − 3x² + 2, temos f′(x) = 3x² − 6x e f″(x) = 6x − 6. No ponto crítico x = 2, f′(2) = 0 e f″(2) = 6 > 0, comprovando que x = 2 é um ponto de mínimo.

Problemas de Otimização na Engenharia

Na engenharia, otimizar significa projetar um sistema para obter o máximo rendimento (área, volume, lucro, potência) ou o mínimo dispêndio (custo de material, perda de energia, tempo de resposta). O cálculo diferencial resolve problemas de otimização transformando restrições físicas em uma função de uma única variável e buscando seus pontos críticos.

Exemplo resolvido passo a passo (Otimização de área de um cercado industrial): Um engenheiro dispõe de 120 metros de tela para cercar uma área retangular de armazenamento aproveitando um muro já existente em um dos lados (portanto, a tela cobrirá apenas 3 lados: dois lados de largura x e um lado de comprimento y). Quais dimensões maximizam a área cercada?
Passo 1 (Restrição e função-objetivo): O comprimento da tela é 2x + y = 120 ⇒ y = 120 − 2x. A área é A(x) = x · y = x(120 − 2x) = −2x² + 120x.
Passo 2 (Ponto crítico): Derivamos A(x) e igualamos a zero: A′(x) = −4x + 120 = 0 ⇒ 4x = 120 ⇒ x = 30 m.
Passo 3 (Validação pelo Teste da 2ª Derivada): Como A″(x) = −4 < 0, x = 30 m garante um ponto de máximo. O outro lado mede y = 120 − 2(30) = 60 m, resultando na área máxima A(30) = 30 × 60 = 1.800 m².

Identifique a grandeza que deve ser maximizada ou minimizada e use a equação de restrição do problema para escrevê-la como função de uma única variável f(x).

Derive a função-objetivo e resolva a equação f′(x) = 0 dentro do domínio fisicamente válido (por exemplo, comprimentos e tempos positivos).

Confirme a natureza do extremo: f″(x) < 0 comprova que você encontrou o desempenho máximo, enquanto f″(x) > 0 comprova o custo ou desperdício mínimo.
